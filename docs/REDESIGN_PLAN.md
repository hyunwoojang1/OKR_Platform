# REDESIGN_PLAN.md — 대개편 설계 확정 (2026-08-24 그릴 세션)

> v3(딥네이비 대시보드)에 대한 사용자 판정: "AI 냄새, 들어오고 싶지 않음" → 전면 재설계.
> 이 문서가 개편의 단일 기준. 변경 시 여기부터 고칠 것.

## 제품 정의
개인 성장 OKR 플랫폼. 장기 목표를 OKR로 계획하고, 매일의 실행을 기록으로 쌓아,
**아침에 열면 "오늘 뭐 하지" 걱정이 이미 풀려 있는 앱.** 모바일 퍼스트 PWA(폰 홈화면 설치).

## 확정 결정 (그릴 Q1~Q12)
| # | 결정 | 내용 |
|---|---|---|
| Q1 | 첫 집중 탭 | **목표 탭**. 오늘 탭은 다른 기능 완성 후 마지막에 |

| Q5 | 기록 입력 | 체크 원터치(a) + 한 줄 로그 선택(b). AI가 자유 텍스트에서 수치 파싱 |

| Q7 | 목표 탭 v1 범위 | ① AI 챗 목표 생성 + ② 목표 상세(KR 진척·주간 이니셔티브 보드·로그 타임라인). 첫 시나리오 "금융권 하반기 공채 합격" |

| Q12-1 | 계층 다이어트 | **월 마일스톤 삭제.** 영역→Objective→KR+주간 이니셔티브→오늘 할일 |
| Q12-2 | 세션 로그 신설 | **만능 원자**: 할일 체크=자동 로그, 자유 한 줄 기록, 저녁 회고(kind='review')가 한 타임라인. KR에 '로그 집계형(log_agg)' 측정 추가 |
| 기본값 | AI 관계 | 생성 1회성 아님 — **주간 재계획을 함께 하는 지속 코치** (같은 생성 기계 재사용) |

## 세션 로그의 존재 이유 (사용자 동의 완료)
1. KR 자동 측정 — 지표 손 갱신 숙제 제거 (현 대시보드가 죽은 원인 해소)
2. 아침 AI의 기억장치 — "어제 뭐 했는지" 기반 오늘 제안
3. 취준 실전 검색 — 회사별 활동 타임라인(면접 전날, 자소서 재활용)
4. 슬럼프 방어 — 누적 기록의 가시화

## AI 챗 생성 스펙 (구현 대기)
- `/api/ai/okr-chat` 서버 라우트, ANTHROPIC_API_KEY(env), 세션 인증 뒤, SSE 스트리밍
- Claude tool use `propose_okr` → {objective, KRs[지표·측정방식·목표값], weekly_initiatives[4~6주], routines[]} 구조화 출력
- 컨텍스트 주입: 영역·기존 목표·캘린더 마감(채용 30건)·최근 로그
- 초안 카드 편집 → 사용자 "확정" 시에만 DB 저장
